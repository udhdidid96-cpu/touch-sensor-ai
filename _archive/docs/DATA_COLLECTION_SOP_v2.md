## 3. รายการที่ต้องเก็บ ต่อ 1 เซสชัน

ทำครบทั้ง 3 เซสชัน โดย**ลอกแผ่นออกและติดใหม่**ระหว่างเซสชัน
ตั้งชื่อโฟลเดอร์ `Data/S1/`, `Data/S2/`, `Data/S3/` แล้วภายในใช้ชื่อคลาสเดิม

| คลาส | โฟลเดอร์ | ไฟล์/เซสชัน | ความยาว | วิธีทำ |
|---|---|---|---|---|
| 0 Baseline | `N_base` | 3 | 120 วิ | ติดแน่น ปล่อยนิ่งสนิท ห้ามแตะ |
| 1 Brief Touch | `Brief Touch` | 5 | 90 วิ | แตะจุดต่างๆ ทั่วแผ่น ค้างจุดละ 2–3 วิ แล้วปล่อย ทำซ้ำเรื่อยๆ |
| 1 Press | `Press` | 5 | 90 วิ | กดค้าง 10 วิ ปล่อย 10 วิ สลับ ~4 รอบต่อไฟล์ |
| 1 Friction | `Friction` | 5 | 90 วิ | **ถูผ้าให้แนบขึ้นและช้าลงกว่ารอบแรก** สัญญาณรอบแรกอ่อนเกินไป |
| 2 Peel | `Peel` | 7 | 60 วิ | นิ่ง 15 วิ → ค่อยๆ ลอกจนหลุด → ค้าง 20 วิ **ต้องเห็นค่า ≤ 25,000** |
| 3 Vertical Pull | `VPull` *(หรือ `Vertical Pull NO G`)* | 7 | 90 วิ | นิ่ง 10 วิ → ดึงขึ้น ~10 mm/s จนแผ่นเริ่มลอย → ปล่อย → ทำซ้ำ 3 รอบ |
| 3 Horizontal Pull | `HPull` *(หรือ `Horizontal Pull NO G`)* | 7 | 90 วิ | เหมือนกันแต่ดึงขนานผิว |
| 3 Powerful Pull | `PowerP` | 5 | 60 วิ | ดึงแรงกว่าปกติ ทั้งแนวดิ่งและแนวราบอย่างละครึ่ง |

**รวม 44 ไฟล์/เซสชัน × 3 = 132 ไฟล์** ประมาณ 2 ชั่วโมงต่อเซสชันรวมพัก

ทุกคลาสได้ ≥ 15 ไฟล์ (P1-1 ผ่าน) Peel ได้ 21 Pull ได้ 57

> **ชื่อโฟลเดอร์ต้องสะกดตรงตามตาราง** โค้ดรับทั้ง `VPull`/`HPull` และ
> `Vertical Pull NO G`/`Horizontal Pull NO G` แต่ถ้าสะกดเป็นอย่างอื่นไฟล์จะไม่ถูกโหลด
>
> **โครงสร้างที่โค้ดอ่านมีแค่ 2 แบบเท่านั้น:**
> `Data/<คลาส>/` กับ `Data/S<เลข>/<คลาส>/` — นอกจากนี้ไม่อ่าน
>
> ตั้งแต่ v6.4 ถ้ามี CSV อยู่ที่อื่น โปรแกรมจะ**บอกทั้งจำนวนไฟล์ที่หายและวิธีแก้**
> เช่น ตั้งชื่อ `Data/Session1/Peel/` จะขึ้นว่า *"rename 'Session1' to 'S1'"*
> หรือเก็บไว้ใน `Data/Peel/retake/` จะขึ้นว่า *"'Peel' is a class folder และโค้ด
> ไม่อ่านโฟลเดอร์ย่อยข้างใน"*
>
> *(v6.1–v6.3 เตือนเฉพาะโฟลเดอร์ชั้นบนสุด — ถ้าตั้งชื่อ **เซสชัน** ผิด ไฟล์หายเงียบ
> ทั้งเซสชันโดยไม่มีข้อความใดๆ นี่คือบั๊ก D3 ซึ่งแก้แล้วใน v6.4)*

## 4. กฎเหล็ก 5 ข้อ ระหว่างอัด

1. **นิ่ง 5 วินาทีแรกเสมอ** — กดอัดแล้วนับ 1-2-3-4-5 ค่อยเริ่มขยับ
2. **หนึ่งไฟล์ = หนึ่งคลาสเท่านั้น** ห้ามแตะระหว่างอัดไฟล์ Pull
3. **ไฟล์ไหนพลาด ลบทิ้งทันที** อย่าเก็บไว้ "เผื่อ" — `A_VPull_0.csv` (1 แถว) รอบแรกทำให้ต้องเขียนโค้ดกันเพิ่ม
4. **จดใบงาน** ทุกไฟล์: เวลา ผู้ทำ ความเร็วดึงโดยประมาณ อะไรผิดปกติ
5. **ถ่ายวิดีโอ sync** ถ้าทำได้ — จำเป็นสำหรับ P2-2 (วัด lead time เป็นวินาที)

## 5. เกณฑ์ผ่าน — ตรวจก่อนเลิก อย่ากลับบ้านก่อนตรวจ

รันคำสั่งนี้ก่อนเก็บของ:

```bash
python main.py --audit Data/S1
```

ต้องได้ทั้ง 5 ข้อ:

- [ ] Peel อย่างน้อย **8/10 ไฟล์** มีค่าแตะ ≤ 25,000 counts
- [ ] Brief Touch อย่างน้อย **8/10 ไฟล์** มีค่าแตะ > 30,000 counts
      *(v6.4 เช็คเฉพาะ Brief Touch จริงๆ แล้ว — v6.1–v6.3 เอา Brief Touch + Press +
      Friction มารวมกันแล้วขอแค่ 50% ซึ่ง Brief Touch กับ Press ผ่านสองคลาสก็พอ
      ทำให้ Friction ที่ได้ 0/10 มองไม่เห็น ทั้งที่ Friction คือคลาสเดียวที่พังใน P1-4)*
- [ ] **ดูบรรทัด `[note] Friction swing`** — ไม่ใช่เกณฑ์ผ่าน/ไม่ผ่าน (ไม่มีสเปกอ้างอิง)
      แต่ต้องได้มากกว่ารอบแรก (654 counts) ถ้าไม่ถึง ถูใหม่ให้แนบขึ้นและช้าลงทันที
- [ ] **ไม่มีไฟล์ไหน** ขยับก่อนเฟรมที่ 5 (offset ไม่ปนเปื้อน)
- [ ] ทุกไฟล์ยาว ≥ 100 เฟรม
- [ ] Baseline แกว่งไม่เกิน ± 100 counts *(v6.1 บังคับใช้จริงแล้ว — รอบแรก N_Base_01 แกว่ง 234 counts และตกเกณฑ์นี้)*
- [ ] ครบทั้ง 4 คลาส *(v6.1 เช็คให้ — เดิมคลาสหายแล้วเช็คหายตาม)*
- [ ] ไม่มีไฟล์ที่อ่านไม่ได้ / ขนาด 0 ไบต์
- [ ] **ทุก CSV อยู่ในโฟลเดอร์ที่โค้ดอ่าน** *(v6.4 — บรรทัด `every CSV sits in a folder
      the loader reads` ต้องเป็น PASS ถ้า FAIL แปลว่ามีไฟล์ที่เก็บมาแล้วแต่จะไม่ถูกใช้
      โปรแกรมจะบอกชื่อโฟลเดอร์และวิธีแก้ให้ แก้ชื่อโฟลเดอร์แล้วรัน `--audit` ซ้ำ)*

ถ้าข้อไหนไม่ผ่าน เก็บซ้ำเฉพาะคลาสนั้นทันทีขณะ setup ยังอยู่ครบ

## 6. หลังเก็บเสร็จ

"ถ้าไปติดคนใหม่จะยังแม่นไหม" ได้จริง** ตัวเลข LOFO เดิมตอบไม่ได้
