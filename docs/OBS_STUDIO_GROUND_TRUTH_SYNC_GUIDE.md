# คู่มือปฏิบัติการ: การบันทึกภาพและสัญญาณซิงค์ด้วย OBS Studio
## Standard Operating Procedure (SOP): Dual-Stream Ground Truth Data Acquisition
**ระบบ:** Smart Extubation Early Warning System (Project2)  
**เป้าหมาย:** บันทึกวิดีโอมุมมองแท่นทดลองจริง ซิงค์คู่ขนานกับหน้าจอ Web GUI Heatmap เพื่อวัดค่า Lead Time ล่วงหน้าอย่างแม่นยำ

---

## 1. อุปกรณ์ที่จำเป็น (Hardware & Software Setup)

1. **กล้องบันทึกภาพ (High-Speed Webcam / Action Camera):**
   - ความละเอียดอย่างน้อย $1080\text{p}$ ($1920 \times 1080$) ที่ $60\text{ fps}$
   - ขาตั้งกล้อง (Tripod) สำหรับยึดกล้องทำมุม $90^\circ$ (Orthogonal Top-down View) ส่องเห็นแผ่นแปะและสายท่อชัดเจน
2. **แท่นทดลองและอุปกรณ์วัดเชิงกล:**
   - สเกลไม้บรรทัดวัดระยะเลื่อนระดับมิลลิเมตร (Millimeter Scale Grid) ติดข้างแนวสายท่อ
   - เครื่องวัดแรงดึง (Digital Force Gauge / Spring Scale) บันทึกแรงดึงในหน่วยนิวตัน (N)
   - ปั๊มสุญญากาศแรงดูดสูง ($-40$ ถึง $-60\text{ kPa}$)
3. **ระบบซอฟต์แวร์:**
   - **OBS Studio (Open Broadcaster Software):** เวอร์ชันล่าสุด (v30+)
   - **เว็บเบราว์เซอร์:** Google Chrome / Edge เปิดหน้า `http://localhost:8081` ของ Project2 Dashboard
   - **ไดรเวอร์ Serial / CDC:** สำหรับเชื่อมต่อบอร์ดเซนเซอร์ 25 แชนแนล

---

## 2. การตั้งค่า Canvas ใน OBS Studio

1. **เปิด OBS Studio** และไปที่ **Settings -> Video**:
   - Base (Canvas) Resolution: `1920x1080`
   - Output (Scaled) Resolution: `1920x1080`
   - Common FPS Values: `60` (สำคัญมากสำหรับการจับความเร็วในการดึงระดับมิลลิวินาที)
2. **สร้าง Scene ใหม่ชื่อ:** `Extubation_Experiment_Bench`
3. **เพิ่ม Source 1 (ฝั่งซ้าย - การทดลองจริง):**
   - คลิกเครื่องหมาย `+` ใน Sources -> เลือก **Video Capture Device**
   - เลือกกล้องเว็บแคมของคุณ -> ปรับ Resolution เป็น `1920x1080`, FPS: `60`
   - ปรับตำแหน่งให้ครอบคลุมครึ่งซ้ายของหน้าจอ (พิกัด $X=0, Y=0$, กว้าง $960\text{ px}$)
4. **เพิ่ม Source 2 (ฝั่งขวา - หน้าจอโปรแกรม GUI):**
   - คลิกเครื่องหมาย `+` ใน Sources -> เลือก **Window Capture**
   - เลือกหน้าต่างเบราว์เซอร์ที่เปิดโปรแกรม Project2 Dashboard
   - ปรับตำแหน่งให้อยู่ครึ่งขวาของหน้าจอ (พิกัด $X=960, Y=0$, กว้าง $960\text{ px}$)
   - ซูมให้เห็นองค์ประกอบสำคัญ 3 อย่าง:
     - **25-Pad Heatmap Grid** (การกระจายตัวของสนามความจุไฟฟ้า)
     - **CPRI & Severity Gauge** (ระดับการเตือน Level 0, 1, 2, 3)
     - **Frame Index / Timer Telemetry**

## 3. ขั้นตอนการซิงค์เวลา (Time Synchronization Beacon)

เพื่อให้เวลาในวิดีโอจากกล้องเว็บแคมและเวลาของแพ็กเกจข้อมูลเซนเซอร์ในคอมพิวเตอร์ตรงกันระดับมิลลิวินาที:

### วิธีที่ 1: Visual LED Flash / Marker
1. ติดตั้งหลอดไฟ LED หรือแฟลชขนาดเล็กไว้ในมุมมองของกล้อง
2. เมื่อเริ่มบันทึก ให้กดส่งคำสั่งหรือแตะสวิตช์แฟลชให้ไฟติดวาบ 1 ครั้ง
3. จังหวะที่ไฟแฟลชสว่างวาบ ให้กดปุ่ม `Start Stream` หรือบันทึก Frame Index แรกในระบบ
4. ในขั้นตอนตัดต่อวิเคราะห์ Frame ที่ไฟแฟลชสว่างคือ $t=0.000\text{ s}$

### วิธีที่ 2: Contact Clapper Tap
1. ใช้วัตถุสัมผัสหรือนิ้วแตะเคาะลงบนแผ่น Pad หมายเลข 13 (จุดศูนย์กลาง) 1 ครั้งสั้นๆ
2. กล้องจะจับภาพการแตะ ขณะที่หน้าจอ GUI จะเกิดกราฟ Spike พุ่งขึ้นทันทีในเฟรมนั้น
3. กำหนดให้เฟรมที่เกิด Spike คือจุดศูนย์อ้างอิงเวลา (Sync Reference Frame)

## 4. ขั้นตอนการบันทึกการทดลอง (Experiment Protocol)

1. **Warm-up & Baseline:**
   - เริ่มบันทึกวิดีโอ (Start Recording ใน OBS)
   - เปิดระบบเซนเซอร์และปล่อยให้อยู่ในสถานะนิ่ง (Resting) เป็นเวลา $5 - 10\text{ วินาที}$ เพื่อตรวจสอบว่าสัญญาณอยู่ใน Noise Gate ($\pm 60\text{ counts}$) และระบบเตือนภัยอยู่ที่ Level 0
2. **Execute Interaction (ตาม 5 สถานการณ์):**
   - **Touching:** ใช้นิ้วมือกดแผ่นแปะเบาๆ $2-3$ วินาที แล้วปล่อย
   - **Friction:** ใช้ผ้าหรือถุงมือแพทย์ถูกับหน้าสัมผัสแผ่นแปะและสายท่อ
   - **Peeling:** ค่อยๆ ลอกมุมแผ่นแปะออกทีละแถว
   - **Vertical Pull:** ดึงสายท่อขึ้นในแนวตั้งฉากจนแผ่นเริ่มยกตัว
   - **Horizontal Pull:** ดึงสายท่อขนานไปกับแนวผิวสัมผัสด้วยความเร็วสม่ำเสมอ ($\approx 10\text{ mm/s}$)
3. **End of Episode:**
   - เมื่อท่อหลุดออกจากตำแหน่งวิกฤต บันทึกเวลาต่ออีก $5\text{ วินาที}$ แล้วกด Stop Recording

## 5. การวิเคราะห์ผลและการคำนวณ Lead Time (Analysis & Lead Time Calculation)

หลังเสร็จสิ้นการบันทึก นำไฟล์วิดีโอ `.mp4` หรือ `.mkv` จาก OBS Studio มาเปิดในโปรแกรมตัดต่อวิดีโอ (เช่น DaVinci Resolve, Adobe Premiere หรือโปรแกรม Python OpenCV):

```
+-----------------------------------------------------------------------------------------+
|                                    LEAD TIME TIMELINE                                   |
|                                                                                         |
|  Frame 0: Sync Marker                                                                   |
|     │                                                                                   |
|     ▼                                                                                   |
|  Frame T_1: ผู้ป่วยเริ่มดึงท่อ (Physical Motion Detected by Camera)                     |
|     │                                                                                   |
|     ▼                                                                                   |
|  Frame T_alarm: หน้าจอ GUI เปลี่ยนเป็น Level 2 (Warning) หรือ Level 3 (Critical Alert)  |
|     │                                                                                   |
|     │◄─────────────────── Lead Time (เตือนล่วงหน้า 3.2 - 5.6 วินาที) ─────────────────►│|
|     ▼                                                                                   |
|  Frame T_loss: สายท่อหลุดจากทางเดินหายใจอย่างสมบูรณ์ (Physical Extubation Event)        |
+-----------------------------------------------------------------------------------------+
```

**สูตรการคำนวณ:**

$$\Delta t_{\text{lead}} = \frac{\text{Frame}_{T_{\text{loss}}} - \text{Frame}_{T_{\text{alarm}}}}{\text{FPS}}$$

ตัวอย่างเช่น:
- กล้องบันทึกที่ $60\text{ fps}$
- หน้าจอเตือนภัยติด Level 2 ที่เฟรม `1,200`
- สายท่อหลุดออกจากแท่นทดลองจริงที่เฟรม `1,512`
- ค่า Lead Time คือ:
  $$\Delta t_{\text{lead}} = \frac{1512 - 1200}{60} = \frac{312}{60} = 5.20\text{ วินาที}$$

ค่า Lead Time นี้จะเป็นหลักฐานเชิงประจักษ์ทางการแพทย์ที่ทรงพลังที่สุดในการรายงานต่ออาจารย์ที่ปรึกษาและคณะกรรมการประเมินโครงการวิจัย
